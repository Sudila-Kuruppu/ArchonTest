# Epic 2: Product Catalog Management — DressCave

## Epic Goal
Enable store administrators to manage the product catalog including creating products with variants, uploading images, organizing by categories, and marking items as featured/new arrivals.

## Functional Requirements Covered
FR1: Admin can create new products with name, description, category, price, and base sizes
FR2: Admin can upload multiple images per product
FR3: Admin can set product variants (colors, sizes)
FR4: Admin can organize products into categories (Women, Kids, Men) and subcategories
FR5: Admin can edit existing product details
FR6: Admin can delete products from the catalog
FR7: Admin can mark products as featured or new arrivals

## Stories

### Story 2.1: Create Products Table in Database
Create the products table in Supabase with all required fields (id, name, description, category, subcategory, price, sizes[], colors[], images[], is_featured, is_new_arrival, age_range, created_at, updated_at). Add indexes on frequently queried columns. Enable RLS: public read, admin write. Implement as a SQL migration file.

### Story 2.2: Product Creation Form
Admin form with fields: name, description, category dropdown, subcategory, price, size checkboxes, color picker, age range (if Kids), image upload. Saves to Supabase, redirects to product detail.

### Story 2.3: Edit Existing Product Details
Pre-filled edit form for products. Update any field, toggle featured/new arrival, add/remove images. Changes reflected immediately on storefront.

### Story 2.4: Delete Product from Catalog
Soft delete with confirmation dialog. Product no longer appears in catalog. Related records (reviews, orders) remain intact.

### Story 2.5: Manage Product Categories
CRUD for categories (Women, Kids, Men) and subcategories. Category hierarchy stored and maintained. Category navigation appears on storefront.

### Story 2.6: Mark Products as Featured or New Arrivals
Toggle is_featured and is_new_arrival flags on products. Featured products appear in homepage section. "New" badge on new arrivals. Configurable limits.

### Story 2.7: Product Image Upload and Management
Upload multiple images per product to Supabase Storage. Auto-optimize (WebP, max 1200x1600). Drag-and-drop reorder, set primary, delete individual images.
