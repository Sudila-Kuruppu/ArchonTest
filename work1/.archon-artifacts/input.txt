# Epic 1: User Authentication & Account Management

## Epic Goal
Enable users to create accounts, log in securely, save custom measurements for made-to-order clothing, and manage their profiles. This epic delivers core user identity and personalization features that enable saved cart/wishlist persistence (FR21-FR25) and AI customer service (FR29-FR32).

## Functional Requirements Covered
- FR16: Users can create an account with email and password
- FR17: Users can log in to their account
- FR18: Users can reset their password
- FR19: Users can save custom measurements in their profile
- FR20: Users can edit their profile information

## Stories
1.1: User Registration Flow — signup with email/password, email verification via Supabase Auth
1.2: User Login Flow — login with email/password, session via HttpOnly cookies, personalized greeting
1.3: Password Reset Flow — forgot password via email, secure reset link, password update
1.4: Save Custom Measurements in Profile — chest, waist, hips, inseam, height, weight; unit conversion (cm/inches); multiple profiles
1.5: Edit Profile Information — name, email, communication preferences; email change requires verification
1.6: Account Deletion (GDPR Compliance) — self-deletion with password confirmation, 30-day data retention, GDPR compliance (NFR7)
1.7: User Menu and Navigation — dropdown menu with My Account, Measurements, Wishlist, Cart, Settings, Logout; mobile accessible

## Tech Stack
- Next.js 14.x App Router, React 18.x, TypeScript 5.x
- Supabase Auth (email/password, HttpOnly cookies via @supabase/ssr)
- Zod validation, React Hook Form
- Zustand for client state, shadcn/ui components
- Tailwind CSS 3.4+
