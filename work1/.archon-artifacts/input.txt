# JobScraper MVP — Full Stack Implementation

## Description
Build the complete MVP for JobScraper, a multi-board job aggregation web app. This is a greenfield project — no code exists yet.

## P0 Requirements (all must be implemented)

### FR-01: Multi-board search
Search across 3+ job boards (LinkedIn, Indeed, and at least one more such as Glassdoor or SimplyHired) in a single query.

### FR-02: Keyword & location input
Accept keyword and location input from the user for search queries.

### FR-03: Unified results display
Display search results in a unified list with title, company, location, and a link to the original posting.

### FR-04: Save/bookmark listings
Allow users to save/bookmark an unlimited number of job listings to a personal collection.

### FR-05: User registration & login
Support user registration and login to persist saved jobs and preferences. Passwords must be hashed with bcrypt.

### FR-06: Export to CSV & Excel
Allow users to export search results or saved listings to CSV and Excel formats.

### FR-07: Graceful error handling
Surface errors gracefully when a specific job board is unreachable or returns no results.
