# Coffee Shop

A multi-page coffee shop website built with Node.js, Express, and EJS.

## Pages

- **Home** — Hero section with featured coffees
- **Menu** — Full coffee menu with prices and categories
- **About** — Story, mission, and location
- **Contact** — Form with server-side validation

## How to Run

```bash
cd coffee-shop
npm start
```

Then open **http://localhost:3000** in your browser.

## Tech Stack

- Node.js + Express
- EJS templating (partials for header, nav, footer)
- Responsive CSS (mobile-first, coffee-themed)
- Client-side JS (hamburger menu, form validation)
